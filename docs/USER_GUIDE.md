# 用户手册（WukongMM 1.0）

[English](USER_GUIDE.en.md)

## 1. 安装
1. 安装 [.NET 10 桌面运行时（x64）](https://dotnet.microsoft.com/download/dotnet/10.0)（已装过可跳过）。
2. 下载 `WukongMM-<版本>-win-x64.zip`，解压到任意文件夹，运行 `WukongMM.exe`。不需要管理员权限（游戏装在 `C:\Program Files` 时除外）。
3. 首次运行会扫描 Steam 库自动找到游戏；找不到时到 **设置 → 游戏目录** 选择包含 `b1` 文件夹的那一层（例如 `...\steamapps\common\BlackMythWukong`）。
4. 右上角的 **English / 中文** 按钮切换界面语言，会记住你的选择。

管理器自己的数据：设置和道具名称备注在 `%APPDATA%\WukongMM`；mod 备注、禁用仓库、存档备份在 `游戏目录\b1\ModManager`。
卸载：删除程序文件夹和上面两个目录即可（先在管理器里把要保留的 mod 都启用，否则它们还在禁用仓库里）。

## 2. Mod 管理
- 按作者说明把 mod 放进游戏目录（例如 pak 放 `b1\Content\Paks\~mods`），点 **刷新**。
- **勾选 = 启用，取消勾选 = 禁用**。禁用会把 mod 的文件移到 `b1\ModManager\Disabled`（保留原来的相对路径），不删除；再勾选就移回去。游戏运行时不能切换。
- 识别规则：`~mods` 里同名的 `.pak/.utoc/.ucas/.sig` 算一个 mod，`~mods` 的子文件夹算一个 mod；`LogicMods` 同理（需要 UE4SS）；
  `Binaries\Win64\CSharpLoader\Mods\<名称>` 算一个 C# mod（需要 CSharpLoader）；`Binaries\Win64\ue4ss\Mods\<名称>` 算一个 UE4SS mod。
  UE4SS 自带的内置脚本默认隐藏（勾选"显示框架内置组件"可显示）。
- **自定义 mod**：有些 mod 分散在两处（例如 UE4SS 脚本 + pak），用"新建自定义 mod…"把它们组合成一个，一起开关。删除分组不会删除文件。
- **状态"重复"**：游戏目录和禁用仓库里各有一份（通常是禁用后又装了一次），请打开文件夹删掉不要的那份再刷新。
- **资源冲突**："冲突"列的数字表示和多少个 mod 改了相同的游戏文件：`⚠ N` = 双方都启用、正在冲突；纯数字 = 其中一方禁用，暂时没冲突。
  选中 mod 可在右侧看到冲突对象和相同的文件；启用会冲突的 mod 前会弹出确认。两个改同一张数据表的 mod 同时启用时只有一个生效。
- **-fileopenlog**：很多 pak mod 要求用 `-fileopenlog` 参数启动游戏才生效。设置页默认勾选，右上角"启动游戏"按钮会带上这个参数；也可以在 Steam 启动选项里填。
- 每个 mod 可以填显示名、来源链接、备注（保存在 `b1\ModManager\mods.json`）。

## 3. 存档修改
**改之前请完全退出游戏。** 每次写入前都会自动备份，出问题在左下"备份"里选一项还原。

### 3.1 先装导出 mod（推荐）
存档页要靠游戏自己的数据表显示道具名称、携带上限，并判断哪些道具可以修改。数据由管理器自带的 **WukongMMDataExport**（只读的 CSharpLoader mod）在游戏读档后导出：
1. 安装 [CSharpLoader](https://github.com/czastack/B1CSharpLoader)（把 `version.dll` 和 `CSharpLoader` 文件夹放进 `b1\Binaries\Win64`）。
2. 设置页 → **安装 / 更新导出 mod**。
3. 启动游戏读一次档（进到能操控角色即可），退出。数据保存在 `b1\ModManager\GameData`。
4. 想要英文道具名：把游戏的文字语言切成英文再读一次档，然后可以切回中文。
没有导出数据时管理器使用内置表（与游戏 1.0.21 一致），但没有道具名称和携带上限。

### 3.2 角色
- **等级**：只能填游戏等级表里的等级（1.0.21 为 1~342）。勾选"升级时按等级表补发灵光点"会把升级应得的灵光点加上（直接改等级游戏不会给点）。降级不会收回已加到天赋上的点。
- **灵蕴**：建议不超过 999,999,999（游戏以 int32 计算，接近 21 亿会溢出）。
- **当前经验**：本级已获得的经验，不能达到升下一级所需；累计经验自动同步。
- **灵光点**：未分配的点数，最多 9999。
- 存档里原有的不合规值（例如别的工具改出来的）不改它就不会挡住保存，只在确认框里提醒。

### 3.3 道具
- 列表只显示**打造、炼丹、升级用的材料，以及丹药和种子**，分为：丹药、药材、种子、兵器材料、防具材料、珍稀材料（Boss 掉落的关键材料、玲珑内丹）、升级材料（精魄升级）。
  剧情 / 任务道具（如神魂·X将）、只用于兑换的道具（如佛手·左/右）、只能卖钱的金片等不显示，存档里原样保留。
- 用 **类别** 下拉框只看某一类（例如只看种子）；搜索框按 ID / 名称 / 类别筛选；"只看已修改"。
- 双击"数量""仓储"修改。数量超过"上限"会标红（游戏不报错，但之后捡不到、买不到，直到数量降到上限以下）。丹药可以超过上限，多出的进仓储。
  "仓储"是在神龛休息时自动补进数量的存货。
- **新增道具**：输入名称（自动补全）或 ID，填数量后点"添加"。种子一旦在背包里有条目（哪怕数量 0），就不会再从敌人 / 宝箱掉落，会先提醒。
- "名称"可以双击改成自己的备注（保存在本机，不影响游戏）。

### 3.4 保存与还原
- 点 **保存到存档**，确认框列出所有改动和"注意"事项，确认后写入：自动备份 → 写入 → 重算校验值 → 自检。
- Steam 云同步开启时，下次启动游戏 Steam 一般会上传本地新存档；如果弹出冲突，选"本地"。
- **还原**：在"备份"里选一项 → 还原所选备份（还原前会再备份一次当前存档）。备份位于 `b1\ModManager\SaveBackups\<SteamID>`。

## 4. 常见问题
- **启用了 mod 没效果**：pak mod 是否用 `-fileopenlog` 启动；C# mod 需要 CSharpLoader；UE4SS / LogicMods 需要 UE4SS（且 UE4SS 本身没被禁用）。看 Mod 页每个 mod 的提示。
- **游戏提示存档损坏 / 读档失败**：在"备份"里还原最近一次备份。请把情况反馈到 GitHub Issues。
- **按钮都是灰的**：游戏正在运行（右上角显示"游戏运行中"），退出游戏即可。
- **游戏更新后**：重新进一次游戏读档，让导出 mod 更新数据表。存档格式变化时管理器会提示"结构无法识别"，此时不要修改。

## 5. 命令行（高级）
`wmm.exe`（源码构建得到）：`wmm mods list|enable|disable|conflicts`、`wmm items`（列出可修改道具）、`wmm info <存档>`、`wmm apply <存档> ...`（与界面相同的规则、自动备份）、`wmm selftest`。
